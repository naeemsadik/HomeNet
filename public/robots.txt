# HomeNet (https://www.homenetbd.com): Bangladesh property listings, direct
# from owners. Search engines and AI answer engines are welcome to crawl every
# public page: listings, area pages, guides and the sitemap.
#
# Disallowed below: signed-in workspaces with nothing for a crawler to read.
# The other signed-in pages (/profile, /settings, /notifications, /verification,
# /property/create, /property/edit) stay crawlable on purpose: they carry a
# noindex tag (src/lib/seo.ts), and a page blocked here could never be fetched
# for that tag to be seen.
#
# Each crawler reads only the group that names it, so every group repeats the
# same rules. Groups with several User-agent lines share one rule set.
# "/seller$" plus "/seller/" blocks the workspace but not a future page such
# as /seller-guide, which a bare "/seller" prefix would also catch.
