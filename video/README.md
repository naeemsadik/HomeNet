# HomeNet promo video (Remotion)

A 99-second Bangla promo for HomeNet, rendered with [Remotion](https://remotion.dev) and synced
to the final voiceover. This folder is a standalone package: it has its own `package.json` and
`node_modules`, and nothing in the app imports from it. The root `tsconfig.json` and
`eslint.config.js` exclude `video/` so app checks are unaffected.

## Render

Requires Node 18+. No system ffmpeg is needed; Remotion bundles its own.

```bash
cd video
npm install
npm run studio     # live preview at http://localhost:3000, scrub the timeline
npm run render     # writes out/homenet-promo.mp4 (1920×1080, 30 fps, H.264, CRF 18)
```

If Remotion cannot download Chrome (offline CI), pass an existing binary:
`npx remotion render src/index.ts HomeNetPromo out/homenet-promo.mp4 --browser-executable=/path/to/chrome-headless-shell`

Other useful commands:

- `npm run sfx` regenerates the synthesized sound effects in `public/sfx/`.
- `REMOTION_BROWSER=/path/to/chrome node scripts/stills.mjs 12.5 38.8` renders half-size
  check frames at those seconds into `out/`.
- `npm run typecheck`.

## How sync works

The voiceover (`public/audio/voiceover.mp3`, 99.08 s) is the master clock. The composition is
`ceil(99.082 × 30) = 2973` frames, so picture and sound end together.

Every pause in the audio was located with:

```bash
ffmpeg -i public/audio/voiceover.mp3 -af silencedetect=noise=-32dB:d=0.18 -f null -
```

That gives 32 pauses, and each speech island between them maps to one clause of the script
(for example 7.85–8.17 s is "তাই তো?", 95.94–96.47 s is "হোমনেট।"). Word cues inside a
clause are placed by syllable count across the island. All cues live in `src/timeline.ts`
as seconds; components take a cue and start their motion 4 frames early so it lands on the
word. To retime anything, edit the number in `timeline.ts`, nothing else.

## Brand sources

- Colours: copied from the app's `src/theme/colors.ts` (`colorTokens`) into `src/theme.ts`.
  Ink `#0B1A17` and canvas `#F8FAF9` are the two scene grounds, brand green `#04cf92` is the
  single hero colour, `brandText` for green text on light, `info` blue only on the verified badge.
- Logo: `brand/homenet-logo.svg` and `brand/homenet-logo-reverse.svg` (background removed for
  the transparent dark variant).
- UI: reconstructed in React/CSS from `PropertyCard.tsx`, `HeroProductVisual.tsx`, the search
  widget and Bangla strings in `src/i18n/locales/bn.ts`. The only photo is the app's own
  `assets/auth-hero-building.webp` (shown with slow Ken Burns, cropped differently per card).
- Fonts: Anek Bangla (display) and Noto Sans Bengali (UI/body), variable fonts in
  `public/fonts/`. Line height is 1.42 for display and 1.6 for body, and words are never
  masked, so Bengali matras and conjuncts don't clip.

## Audio

Voiceover at full volume, a very low synthesized pad (6%), and small synthesized SFX (whoosh,
pop, tick, sub hit) placed 3 frames before the visual they accent. All SFX are generated by
`scripts/make-sfx.mjs`, so there are no third-party audio licences to track.
